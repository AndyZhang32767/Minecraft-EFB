# EFB

Minecraft **1.21.11 / Fabric / Java 21** 自适应客户端／服务端航空航图模组，当前版本 0.10.0。

以航空航图、ND 仪表为交互参考，自行绘制标注界面。卫星底图直接使用已安装的 Xaero's World Map；纯色航图和 ND 可独立使用。不包含 Xaero 或 Navigraph 的代码、素材或地图文件。支持 NDB、VOR/DME/VORDME 和 ILS 导航台，以及两套独立无线电调谐；本版不增加无线电 HUD/ND 导航显示。

## 安装与开发

1. 安装 Minecraft 1.21.11、Fabric Loader **0.18.4 或更高**。
2. 将 **Fabric API 0.141.4+1.21.11** 和本项目构建得到的 `build/libs/efb-0.10.0.jar` 放入游戏实例的 `mods` 目录。卫星底图需要同实例安装 **Xaero's World Map 1.41.2（Minecraft 1.21.11 Fabric 版）**。
3. 自动驾驶需要另行安装 **FlightAssistant 3.0.1（1.21.11 Fabric）** 及它要求的 Fabric Language Kotlin、Architectury、YACL。EFB 不打包或修改 FA，服务端不需要安装 FA。启动时自动检测 FA；未安装或兼容接口未能初始化时，隐藏并禁用 PERF/性能和 TMPY/应用，航图、个人计划及 ND 仍可使用。
3. 进入单人世界或服务器，按 **N** 打开航图。服务器端可选安装同一 JAR 以启用共享航图，详见 [服务器同步](SERVER_SYNC.md)。
4. 中文界面随 Minecraft 的「简体中文」语言设置启用。

Windows 开发命令（需要 JDK 21）：

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat test
.\gradlew.bat runClientGameTest
.\gradlew.bat runClientGameTest -PwithFlightAssistant
```

macOS / Linux 使用 `./gradlew`；若从 Windows 复制后没有执行权限，先执行 `chmod +x gradlew`。发布时使用普通 JAR，不使用 `-sources.jar`。首次构建需要联网下载 Gradle 与 Minecraft 依赖。Gradle 发行包使用腾讯镜像，固定版本并校验官方 SHA-256。

| 按键 | 功能 |
| --- | --- |
| N | 打开/关闭航图 |
| V | 切换 ND 的 NAV / ARC 模式 |
| B | 循环切换 ND：飞行/骑乘时、始终显示、隐藏 |
| Page Down / Page Up | 减小 / 增大 ND 量程 |
| F | 航图中回到当前位置 |
| 滚轮 | 航图中以鼠标位置为中心缩放；列表中滚动 |
| 拖动 | 平移地图 |

N / V / B / Page Down / Page Up 均可在 Minecraft「选项 → 控制 → 按键绑定 → EFB 航空导航」中修改。量程键已从旧版方括号键迁移，避开 Xaero 的默认 `]` 设置键。

## 航图、机场与跑道

- **航点**：选择顶部「航点」，点击地图空白处直接放置航点并立即打开左侧编辑栏；服务器确认后编辑栏保持打开。双击已有航点也可在左侧栏编辑标识和 X/Z。也可使用「在当前位置添加」。
- **机场**：选择「机场」后创建机场标注。机场本身也可以作为飞行计划的一个点。
- **跑道与程序**：选择「机场」并点击机场，在左侧栏直接管理跑道和程序。添加跑道后依次点选两端；支持 X/Z、标高、宽度和完整编号（例如 `27L/09R`），两端分别识别为 `27L`、`09R`。
- **程序**：按 ARR 的 STAR 方向，从外向内点选航点或输入标识，可绑定某一到达跑道端或适用全部跑道。左键追加，右键撤销末点，保存前青色预览。同一程序可反向作为 DEP 的 SID 使用，绑定跑道时使用另一端；ARR 只有 STAR，没有 APP。
- **标点坐标**：表单和地图坐标显示整数，新增或编辑后的 X/Z 使用该方块中心 `.5`（例如输入 `-10`，实际坐标为 `-9.5`）。旧数据升级保留原坐标。
- **缩小隐藏**：底部比例尺达到 867b 时，地图航路保留连线和相连航点符号，隐藏名称；当前 ROUTE/F-PLN 个人计划保留全部航点及航线（包括孤立点、程序点和跑道起始点），仅隐藏文字，断点不跨线连接。其他没有航路连接的导航点完全隐藏，单独的 SID/STAR 程序不算航路连接。未加入计划的机场仍显示名称，跑道和公共程序隐藏。正在配置的导航台保留符号、范围和方向标记。放大后恢复，列表保留完整内容。
- 选择导航点后可在左侧编辑、定位、删除。删除一个导航点会在该点处分割地图航路，并移除所有飞行计划中对该点的引用、保留断点；删除机场还会移除其跑道和程序，操作前有确认提示。
- 距离以方块（`b`）计，速度为 `b/s`；X 向东、-Z 向北。首版不做经纬度或真实航海里换算。

机场标识与 WPT/NDB/VOR/ILS 标识允许重名；机场之间、非机场导航点之间仍不允许重名。INIT DEP/ARR 和跑道机场字段仅查找机场，航路输入优先查找非机场导航点。

## 导航台与 RAD/NAV

在「航点」界面点击 **NDB / VOR**，直接在玩家所在位置创建对应导航台，自动生成该类型的合法随机频率，优先使用未占用频道。导航台属于公共航图；本地可编辑，联机由 OP 编辑，普通玩家可查看及使用。

参数在左侧栏编辑，滚轮查看下方字段，点击「保存」提交：

| 类型 | 参数 |
| --- | --- |
| NDB | 标识、X/Y/Z、频率、有效半径 / b |
| VOR | 标识、X/Y/Z、VOR / DME / VORDME 模式、频率、正北偏角、有效半径 / b |
| 跑道 ILS | 在跑道设置中开启；两端频率、下滑道距离比；标高来自机场，方向来自跑道 |

NDB 使用 **190–1750 kHz** 的整数频道；VOR 使用 **108.00–117.95 MHz** 的 0.05 MHz 频道并排除 ILS 频道。ILS 使用 **108.10–111.95 MHz** 中十分位为奇数的 0.05 MHz 频道（例如 110.30）。输入频率不带单位。

设置导航台时，任意缩放均显示覆盖圆和方向标记；VOR 使用亮蓝色标注，外围使用固定屏幕大小的圆环及向内刻线表示偏角（顺时针为正），随表单实时预览；NDB 使用亮红色标注；ILS 保持原配色，显示相对真北的进场航向（0° 北、90° 东）及方向箭头。正常浏览时，VOR 圆环仅在详细缩放显示；缩小后，有航路连接的导航台只保留符号，没有连接则隐藏。

「飞行计划」右侧的 **RAD/NAV** 提供 RADIO 1、RADIO 2。每套分别选择 NDB / VOR / ILS、输入频率后按 **TUNE**；**CLR** 取消调谐。在同一维度内，类型和频道匹配且水平距离不超过台站半径时显示接收台标识，否则显示 NO SIGNAL。同频时接收有效范围内最近的台站。当前接收只按配置的圆形范围判断，不模拟地形遮挡或 ILS 扇区。

VOR 模式只提供方位，DME 模式只提供距离，VORDME 两者兼有。频率和接收状态位于 RAD/NAV，本版不新增 HUD/ND 无线电导航界面。调谐设置按玩家、世界/服务器和维度独立保存，非 OP 也能调谐，不上传给服务器、不随公共航图刷新而覆盖。

## 两套独立的航路系统

### 地图航路（Airways）

选择「地图航路」，点选两个已有导航点并填写航路名称，保存后继续点第三个、第四个航点，整条航路会持续延长。点击「完成航路」或切换工具结束。每一步立即保存；服务器确认后仍可继续追加。编辑表单支持按顺序输入多个航点标识（空格或逗号分隔）。

编辑器可开启「单向（高空航路）」：按添加航点的顺序通行，以蓝色和方向箭头显示；关闭时支持双向规划。

新建航路时不再绘制跟随鼠标的预览直线。航路名称沿每一段航线旋转，并自动翻正以便阅读；过短的线段隐藏名称，保留连线。可单独删除或清空地图航路，不影响个人计划。

### 飞行计划（ROUTE）

1. 新建入口放在计划侧栏：**ROUTE** 的「新建」取代「删除全部」；**F-PLN** 的 AIRWAYS 行右侧提供 **NEW**。新建时保留当前模式，首次进入计划默认 **ROUTE**。F-PLN 主菜单四行为 **INIT**、**AIRWAYS / NEW**、**CLR**、**PERF / TMPY**。
2. **ROUTE** 是原 DIRECT 地图界面，默认直接点选航点，追加到普通航线末尾、到达程序之前，航段自动设为 **DIR**；选中列表行只选择该行，不移动添加位置。
3. **F-PLN** 全流程使用英文民航术语（包含 INIT、RWY/SID/STAR 选择、输入、确认及错误信息），不随游戏语言翻译。INIT 二级菜单为 **DEP/ARR、DEP RWY/SID、ARR RWY/STAR**；选择程序时青色强调该程序，按 **INSERT*** 才确认插入，返回或切换模式则取消预览。**AIRWAYS** 使用 FROM / VIA / TO 输入，自动以上一航路或程序的终点填写进入点。输入航路和退出点后补全中间全部航点；只填写退出点、航路留空或输入 DIR，则直接添加 DIR。
4. 进入点与前一航点不同或航线尚未接上时，显示 **F-PLN DISCONTINUITY**，地图和 ND 不跨断点连线，导航在断点暂停。单向航路反向规划会提示错误并保留原计划。
5. **CLR** 左键删除选中航点，右键删除选中的连续航路段；删除后保留断点。断点左侧 **+** 从这里开始编辑；添加到断点后原有航点时自动合并，不重复添加。右侧 **X** 明确删除断点并以 DIR 连接。末端 **+** 返回普通航线末尾继续追加。
6. ROUTE 与 F-PLN 预览、编辑同一个个人计划，切换页面保留补线位置。计划可切换、重命名、重置和删除；DEP/ARR 通过 INIT 修改，确认后保持 F-PLN。机场只作为计划信息，未选择跑道时不计入 WAYPOINT；选择 RWY 后，其对应起始点成为首末航点。共享程序变更时，受影响的个人程序选择会清除并留下断点，需要重新选择。

ROUTE 底部提供「性能 / 应用」，F-PLN 对应「PERF / TMPY」。性能参数按个人计划独立保存，四栏为：

| 页面 | 参数 |
| --- | --- |
| CLB | 起飞俯仰角，1–60° |
| CRZ | 巡航高度 / b、目标速度 / b/s，1–200 b/s |
| DES | 下降率 / b/s（正数）、下降目标高度 / b |
| APPR | ILS 频率 / MHz、APPR SPD / b/s（默认 20，范围 1–200） |

新建计划的 PERF 默认值为：CLB 15°、CRZ 200b / 200b/s、DES 15b/s / 150b、APPR 109.95MHz / 20b/s。已有计划保存的参数不变；选择启用 ILS 的 ARR 跑道后仍自动使用其频率，无 ILS 跑道仍不向 FA 导入 APPR。

PERF 的 INSERT* 只保存参数。F-PLN 列表和地图显示预测的 **T.C**、**T.D**；它们不创建公共航点，也不改变原计划的航点编号。T.C 按高度差和设定角度估算，T.D 按高度差、下降率和目标速度计算，距离沿展开后的全部航段累计。出发高度优先采用 DEP 机场标高（覆盖跑道独立标高，并写入 FA DEP 和首个航点）；普通地图计划使用首次保存 PERF 时的玩家高度。鞘翅实际航迹角受速度和其他模组影响，因此 T.C 是预测位置。

完成 PERF 后按 **TMPY / 应用**，一次性将包含 T.C/T.D 的计划导入 FA 并接通 FD、AP、A/THR；坐标转换沿用 0.8.1。FA 的推力、垂直、水平三个挡位同步选择 **Flight Plan**。EFB 内附客户端兼容 Mixin，仅在 EFB 接管自己的计划时提供 NAV、CLB/CRZ/DES/ILS、SPEED 引导；打开和关闭官方 FA 自动驾驶界面不会覆盖这些引导。断开后恢复 FA 原有计划逻辑。仍使用官方 FA jar，服务器端无需补丁，不修改或重新打包 FA。

AP 只在鞘翅飞行时实际控制，不会从地面自动起跳。有断点、航路长度不足以完成爬升下降、FA 未就绪时不会接管。手动断开、切换控制模式、修改计划、切换世界或维度都会停止 EFB 接管，需要再次 TMPY 才会重新接通。FA 的安全保护保留。

跑道设置新增「启用 ILS」，默认关闭。开启后自动配置跑道两端的 ILS，分别提供可修改的频率；下滑道输入为**每下降 1b 前进多少 b**，默认 20 b/1b（约 2.86°）。方向由跑道几何决定，最终标高始终使用所属机场标高，不使用跑道独立标高。确认 ARR RWY/STAR 的 INSERT* 后，自动填入所选跑道端的 APPR FREQ。

APPR 会调谐个人 RADIO 1。在 T.D 后收到所选跑道端的 ILS、位于前向航道扇区内时，提供 LOC/G/S 引导并使用 APPR SPD；捕获后丢台或改频会断开 AP/A/THR。未启用跑道 ILS 时，FA 的 APPR 保持空白，按 DES 飞完所有航路点后结束 AP/A/THR。官方 FA 3.0.1 不提供独立 APPR SPD 数据字段，因此 EFB 将速度写入进近航点，并通过 EFB 的 FA 接管模式执行，不修改 FA 本体。这里不提供拉平、自动着陆或新增无线电 HUD/ND 显示。

首次读取旧数据库时自动升级到 schema 7，备份为 chart.v旧版本.json.bak，删除旧的独立 ILS，并清空原 ILS 调谐及 APPR 频率；已有跑道默认不开启 ILS。引用已删除 ILS 的航路保留断点，不会自动跨越连接。服务器公共数据库与个人数据库均使用同一升级流程。

目标速度默认 200 b/s，可设置为 1–200 b/s。EFB 接管且目标速度高于 33.33 b/s 时，通过 FA 的推力来源接口替代内置烟花来源，按 PERF 目标速度提供烟花使用请求，不再受官方烟花逻辑约 34 b/s 的触发上限限制，每秒最多一次，达到目标速度后停止请求；只用无爆炸效果的烟花，并保留前方障碍检查。Do a Barrel Roll 等更高优先级的推力来源仍优先。EFB 不修改飞行物理，实际能否达到 200 b/s 由加速模组及服务器决定。

个人计划、PERF、DEP/ARR、VIA 与导航进度均不上传。客户端缓存按**玩家 UUID、世界/服务器、服务器世界 ID、维度**隔离。普通玩家可以用共享导航数据编辑自己的计划。旧计划保留默认 PERF 参数，首次保存 PERF 前不会因点击应用而自动接管。

## 底图

顶部底图按钮切换：

- **纯色**：深色背景加坐标网格，突出航图标注。
- **卫星地形**：Xaero 原生地图纹理，叠加相同的航图标注；只读已由 Xaero 加载的区域。

EFB 只读取 Xaero 当前会话、世界、维度和已有 GPU 纹理，不创建地图区域，不请求加载或重建缓存，不改变纹理计时器、地图设置或文件。纹理按自身区域坐标及层级定位，概览和细节分层绘制。未加载的已探索区域需要先在 Xaero 原界面浏览，让 Xaero 正常加载后再返回 EFB；EFB 不主动加载它们。未探索区域没有地图内容。

不再采样、生成或读取 EFB 自己的 `terrain.bin`，旧文件保留但不使用。无需复制或转换 Xaero 地图。缺少 Xaero、地图尚未就绪或接口不兼容时，航图内显示提示。启动器开启版本隔离时，`xaero` 和 `mods` 都在对应版本的游戏目录下，而不是启动器根目录。切换服务器地图需先在 Xaero 中选对地图。

## ND 面板

默认右上角，默认仅在鞘翅滑翔时显示；创造飞行和骑乘载具不会触发。地面测试可按 **B** 切至始终显示。打开航图或其他菜单时隐藏 HUD。

- **NAV**：航向朝上的完整罗盘视图。
- **ARC**：航向朝上的前向弧形视图。
- 洋红色线表示当前选择的飞行计划；青色引导线指向当前目标。不会把地图航路网络整体画到 ND。
- 字体随 ND 面板缩小（约原字高的 38%–85%）；重叠标签会尝试换位，仍放不下则省略，保留航点符号，优先显示当前目标。
- 显示航向、当前目标、方位、距离、地速、标高及量程；机场作为参考标记显示。
- 航图中的「ND 设置」可调整四角位置、尺寸、显示策略、量程和低空 DIR 半径。
- 量程使用「近 − / 远 +」，按 128 / 256 / 512 / 1024 / 2048 / 4096 / 8192 方块七档切换；尺寸使用「小 − / 大 +」，范围 100–360 GUI 像素（新增 120、100 档）。更改立即保存，关闭航图后生效；小窗口会将面板限制在屏幕内。用 `PgUp` 增大一档显示半径、`PgDn` 减小一档；到上下限后保持该档。自动缩放开启时，按键从当前显示半径切换到相邻手动档，并关闭自动缩放。
- **自动缩放**：ND 设置中可手动开关，默认关闭。开启时按玩家高度 Y 分档调整：Y < 200 为 R128（包含低于 150），200–249 为 R256，250–299 为 R512，300–349 为 R1024，350–399 为 R2048，Y ≥ 400 为 R4096。HUD 标注 AUTO；此时设置中的量程按钮停用；PgUp/PgDn 可切回手动量程。关闭后恢复之前的手动量程，开关和手动量程都保存在本机设置中。
- 高度不超过 150 格时使用设置的低空 DIR 半径；150 至 400 格按线性比例扩大，到 400 格为 200 方块，之后固定为 200 方块。高速穿过捕获区也能识别，连续运动段上限会随该半径扩大；较大的瞬间传送不会跳过中途航点。
- 打开编辑界面时暂停自动切段，关闭后继续。飞完最后一个点后显示完成状态。

ND 提供导航显示，不控制飞行。需要在载具或其他飞行模组中查看时，可手动选择「始终显示」。

## 保存位置

```text
.minecraft/config/airac/
  settings.json
  charts/<世界标识哈希>/<维度标识哈希>/
    chart.json
    chart.json.bak
    chart.v1.json.bak  # schema 1 自动升级前的永久备份
    chart.v2.json.bak  # schema 2 自动升级前的永久备份
    chart.v3.json.bak  # SID 顺序转为 STAR 顺序前的永久备份
    chart.v4.json.bak  # 机场航点转换为跑道起始点前的永久备份
    chart.v5.json.bak  # 添加导航台与双无线电前的永久备份
```

单人世界按存档绝对路径区分，服务器按地址（包含显式端口）区分，主世界、下界、末地分别保存。相同名字的不同路径存档不会混用数据；服务器同名但地址不同也不会混用。若服务器在同一地址重置地图，或代理服在相同地址/维度下切换多个子世界，本地模式下客户端无法自动区分，需要自行备份并管理该地址对应的数据目录。

0.7.0 首次读取 schema 1/2/3/4/5 导航数据时，自动升级到 schema 6。早期双端点航路转为多航点格式，SID 程序按需反转为 STAR 存储方向。个人计划中的 DEP/ARR 机场中心替换为已选跑道起始点；没有选跑道时移除机场中心航点，保留机场信息、途中航点、断点及仍存在的当前目标。升级前保留对应的 chart.v1/v2/v3/v4/v5.json.bak，后续保存不会覆盖。旧账号未区分的计划仅由首次读取它的账号接管，其他账号只继承导航数据。

客户端和服务器都使用 0.7.0 时，进入世界会自动刷新服务器导航数据。共享协议升级为 v6，服务器与客户端需一起更新；无兼容协议时保持本地模式。

标注和计划编辑后立即写入本地 JSON，原子替换文件并保留上一版 `.bak`。遇到损坏或未知版本的航图文件时，保留原文件并进入只读模式，错误会写入日志；可退出世界后检查文件或从备份恢复。本地模式航图仅保存在本机。服务器安装 EFB 0.7.0 后，导航点、机场、跑道、程序和地图航路由服务器保存并同步；个人飞行计划与 ND 设置仍保存在本机。

## 代码与测试

- `data/`：地图对象、两套航路模型、设置与原子存储。
- `nav/`：航向投影、距离计算、顺序航点捕获。
- `map/`：Xaero 已加载区域及原生纹理的只读接入；不保存地形。
- `ui/`：航图、表单编辑器、ND 与设置界面。
- `src/test/`：数据隔离、航路独立性、存储、投影与航点捕获回归测试。
- `src/gametest/`：临时 LAN 世界中的实际网络同步、OP/非 OP 权限和个人计划回归测试，不打入发布 JAR。
